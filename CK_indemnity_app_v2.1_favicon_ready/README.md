# Constantly Kiting Indemnity App

Static GitHub Pages version of the Constantly Kiting indemnity form app.

## Files

- `index.html` — main app page
- `assets/css/styles.css` — app styling
- `assets/js/app.js` — app functionality
- `assets/images/` — optional folder for your logo image

## GitHub Pages setup

1. Upload all files and folders to a GitHub repository.
2. Go to Settings → Pages.
3. Set source to Deploy from a branch.
4. Select branch `main` and folder `/ root`.
5. Open the GitHub Pages URL on iPad Safari.
6. Use Share → Add to Home Screen for kiosk-style use.

## Important

Saved records are stored locally in the browser/iPad storage. They are not uploaded to GitHub.
Use the Export Backup button regularly.


## Logo setup

Add your logo image into:

`assets/images/logo.png`

The app already points to that file. After uploading to GitHub, your header logo will load from the hosted project files.
